One of your mods includes a library named Greenhouse Config.
https://modrinth.com/project/greenhouse-config

Greenhouse Config Meta is a folder for storing metadata relating to configs that the mod may need to perform specific actions.
For example this will store the current schema version of the config, which is then used to fix the config if it is out of date.

As a player you will want to ignore this folder unless a developer tells you to modify something within it.
You are free to delete this folder at any time if you know none of your mods use Greenhouse Config. In this instance it is dead weight within your modpack instance.
